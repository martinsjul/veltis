# Continuidade entre semestres

O Veltis começou no **1º semestre de 2026** e continua no **2º semestre de 2026**. Esta pasta separa o que já existia no início deste semestre (linha de base) do que foi feito agora, com evidências no histórico do Git.

- [Linha de base e evolução — 2º semestre de 2026](linha-de-base-e-evolucao-2026-2.md)
- [Contribuições dos integrantes](contribuicoes.csv) (índice em CSV, separador `;`)

Cuidados adotados:

- Um commit mostra quando e por quem uma alteração foi enviada; não mede sozinho o trabalho de cada integrante.
- "Existia no código" não é o mesmo que "funcionava" ou "foi validado": a validação está registrada em `docs/testes/`.
- Nenhuma credencial ou dado pessoal aparece nas evidências.
