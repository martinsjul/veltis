# Veltis

O **Veltis** é um portal web que apresenta um **mapa interativo da Região Metropolitana de Sorocaba**, permitindo a visualização e análise de dados educacionais e demográficos de forma intuitiva e dinâmica.

## Objetivo

Facilitar o acesso a informações regionais por meio de visualizações geográficas, auxiliando estudantes, pesquisadores, gestores públicos e a população em geral na compreensão dos indicadores da região.

## Funcionalidades

- 🗺️ Mapa interativo da Região Metropolitana de Sorocaba
- 📊 Visualização de dados demográficos
- 🎓 Consulta de indicadores educacionais
- 🔍 Navegação intuitiva por municípios
- 📈 Exibição de informações de forma visual e acessível

## Público-Alvo

- Estudantes e pesquisadores
- Órgãos públicos
- Instituições de ensino
- Cidadãos interessados em dados regionais
